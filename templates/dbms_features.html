    VIEWS — Virtual tables created from SQL queries
    What is a View?
    A VIEW is a saved SQL query stored as a virtual table. Instead of writing a long JOIN query every time, we just call the view name. Views do not store data — they fetch live data each time they are used.

    FUNCTIONS — Reusable SQL logic that returns a value
    What is a Function?
    A FUNCTION takes input values, performs a calculation, and returns a single result. It is called inside a SELECT query just like COUNT() or SUM().
    fn_count_open_issues(project_id)
    Returns the number of open issues for a given project

    TRIGGERS — Auto-execute when database events happen
    What is a Trigger?
    A TRIGGER automatically runs a SQL action when something happens in the database (INSERT, UPDATE, DELETE). No manual call needed — MySQL fires it automatically.
    trg_after_issue_insert
    Fires AFTER INSERT on Issue table.
    Automatically adds a record to Issue_Status_History when a new bug is reported with status = 'open'.
    trg_after_issue_status_update
    Fires AFTER UPDATE on Issue table.
    When status changes (open→in_progress etc.), it auto-inserts old and new status into Issue_Status_History.
