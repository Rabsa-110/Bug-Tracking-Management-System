# 🐞 Bug Tracking Management System

A web-based Bug Tracking Management System developed using **Python, Flask, and MySQL**. This application helps teams efficiently manage software projects by reporting, assigning, tracking, and resolving bugs through a simple and user-friendly interface.

---

## 📌 Features

- User Registration & Login
- Create and Manage Projects
- Report New Bugs
- Assign Bugs to Team Members
- Update Bug Status
- View Bug History
- Dashboard for Managing Issues
- MySQL Database Integration
- Simple and Responsive User Interface

---

## 🛠️ Technologies Used

- Python
- Flask
- MySQL
- HTML5
- CSS3
- Jinja2 Templates

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/Rabsa-110/Bug-Tracking-System.git
```

### 2. Move into the project folder

```bash
cd Bug-Tracking-System
```

### 3. Install the required libraries

```bash
pip install -r requirements.txt
```

### 4. Create the database

Import the `schema.sql` file into your MySQL server.

### 5. Configure the database

Update the MySQL username, password, and database name in the project if necessary.

### 6. Run the application

```bash
python app.py
```
